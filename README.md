## Hi, I'm Fuad 👋

I build things that run on phones, servers and in games, and I take apart the ones that don't behave.

### What I'm up to

| | |
|---|---|
| 🎮 **Games** | [`skyline-jumper`](https://github.com/fuad00/skyline-jumper): 2D side-view base-jumping game for Android & iOS, built with Unity 6 |
| 📱 **Android** | LineageOS bring-up for Nothing Phone (3) and OnePlus 10 Pro: [device tree](https://github.com/fuad00/android_device_nothing_metroid), [vendor blobs](https://github.com/fuad00/proprietary_vendor_oneplus_wly), kernels |
| 🔐 **Security** | [`acubot`](https://github.com/fuad00/acubot) (Acunetix × Telegram), [`wifitool`](https://github.com/fuad00/wifitool), [`jb-ios-contacts-cli`](https://github.com/fuad00/jb-ios-contacts-cli) |
| 🐳 **Self-hosting** | docker-first experiments: [DeepFace × Weaviate PoC](https://github.com/fuad00/docker-deepface-weaviate-example), plus forks of authentik, Zoraxy, Guacamole, NetAlertX |
| 🧠 **Local AI** | running large open models on consumer GPUs: [`Strata`](https://github.com/fuad00/Strata) and [`project-maya`](https://github.com/fuad00/project-maya) forks |
